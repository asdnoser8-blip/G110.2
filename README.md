# 👻 GhostPhish

**أداة صيد متكاملة تضم 35 منصة مختلفة مع لوحة تحكم أنيقة واستقبال فوري للبيانات عبر ntfy.sh**

**المطوّر: الجنرال**  
**الإصدار: 1.0**

---

</div>

## 📌 نبذة عن الأداة

GhostPhish هي أداة احترافية مكتوبة بلغة بايثون، تتيح لك إنشاء روابط صيد جاهزة لـ 35 منصة شهيرة، مع عرض مباشر لبيانات الضحايا في الطرفية بمجرد إدخالهم لبياناتهم في الصفحة المزيفة. تعتمد الأداة على خدمة **ntfy.sh** لنقل البيانات بشكل فوري وآمن، مما يجعلها سهلة الاستخدام ولا تحتاج إلى فتح منافذ أو إعداد خادم خارجي.

---

## ✨ المميزات

- 📋 **35 منصة** مدعومة جاهزة للنشر الفوري.
- 🔔 استقبال البيانات لحظياً عبر إشعارات ntfy.sh.
- 🎨 واجهة طرفية ملونة وسهلة القراءة.
- 🔑 مفتاح سري فريد يتم توليده تلقائياً لكل مستخدم.
- 🌐 روابط الصيد مستضافة على خوادم جاهزة (Render.com).
- 🔄 دعم كامل للغة العربية في عرض البيانات مع تحويل الأرقام العربية.
- 🧹 تنظيف تلقائي للبيانات الواردة من أي نصوص غير مرغوبة.

---

## 🛠️ المتطلبات

- بايثون 3.6 أو أحدث.
- اتصال بالإنترنت.
- أي نظام تشغيل (ويندوز، لينكس، ماك، أندرويد عبر تيرمكس).

لا حاجة لتثبيت أي مكتبات خارجية، فالأداة تعتمد على المكتبات القياسية فقط.
